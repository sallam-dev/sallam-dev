Hi, I'm Mohamed Sallam.

When I started out, the fun was in the problem. Give me something tricky and let me dig into it. Once it worked, I was done, and I wanted the next one.

Then I started inheriting systems. Code that other people wrote, for reasons nobody wrote down, running a business that depended on it every day.

That's where I found out that keeping software working is much harder than getting it to work. I learned to slow down. Asking why a thing is the way it is before changing it. And pushing for a shared language between product and engineering, so less gets lost in translation.

So the fun moved. These days a good day is a long quiet stretch on a real project, building a foundation that a teammate can pick up and build on without fighting it. The best days end with someone telling me their work got easier. A teammate or a customer, I'll take either.

Most of my code lives in private repos, so it's quiet here. I'm easier to find on [LinkedIn](https://www.linkedin.com/in/sallam-dev/).
